# Forecasting Household Deposits in Russia

## 📌 Описание проекта
Построение прогнозной модели объема вкладов физических лиц в России 
на основе макроэкономических факторов (2014–2026).

## 🎯 Цель
Выявить ключевые факторы, влияющие на депозитное поведение населения,
и построить модель для прогнозирования на 2026 год.

## 📊 Данные
- Период: 2014–2026 (ежемесячно)
- Целевая переменная: DEPOS (объем вкладов, млрд руб.)
- 9 факторов: заработная плата, услуги, ставки, инфляция, курс USD, безработица, промпроизводство, импорт
